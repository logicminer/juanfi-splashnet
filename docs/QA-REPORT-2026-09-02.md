## Defects found & fixed during this QA cycle

1. **SDK serving 500** — middleware response-header mutation on static files
   broke `/sdk/splash.js`. Fixed: dedicated route handler with
   `Cache-Control: max-age=0` (self-updating, revalidate-always).
2. **CORS preflight blocked `X-API-Key`** — vendo admin fetch failed
   cross-origin. Fixed: allowed header added globally.
3. **Zone Browser-Cache-TTL override** — Cloudflare forced 4 h caching on
   the SDK (the "frequent flash" trap). Fixed via zone setting → respect
   origin.
4. Lint noise from the third-party JuanFi reference clone — excluded from
   our lint scope.
